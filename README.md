# Foxhound

2026 年高教社杯全国大学生数学建模竞赛 **B 题**项目：无线电干扰源的快速自动定位与清除。

当前第一期是本地「交互演练台」：在地图上手动测向、换频、清除，把题面规则变成看得见的动作，方便读题和对照策略。

## 题意

一只机器狗从原点出发，在半径 1800 m 的圆域内搜索 10–16 个未知频道的干扰源。测向带 ±1° 地点固定误差；先保证全部清除，再尽量缩短虚拟时间。

- 问题 3：全部为全向源
- 问题 4：全向 + 定向（180° 扇形，朝向未知）

完整规则见 [docs/B题规则.md](docs/B题规则.md)。官方原文在 [docs/source/](docs/source/)。

## 运行演练台

需要 Node.js 20+。

```bash
cd web
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器，默认 `127.0.0.1:5173` |
| `npm run build` | 类型检查并打包 |
| `npm run preview` | 预览打包结果 |

## 演练台操作

- 单击地图选定测点，再点 **测向** / **清除**（快捷键 `M` / `C`）
- 右侧 1–20 选择操作频道；`/clear` 不切换测向机当前频道
- 滚轮缩放，拖拽平移
- 「显示真值」：演练可见源位置与覆盖；无源频道会变淡
- 真值开启时，**双击有源频道**可瞄准该源（正式测试没有这个信息）
- 问题 3 / 4、种子、「新开一局」用于换案例

地图会画出示向度射线、±1° 扇区、多点交会区和定位直径。侧栏拆开每一步的移动 / 换频 / 动作耗时。

判定与官方一致：同点重复检测误差不变、`near` 为距离 ≤ 5 m、清除半径 20 m 且与定向朝向无关、`no_signal` 不等于附近没有源。
